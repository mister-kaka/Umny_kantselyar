## Скриншоты

Все скриншоты страниц находятся в папке screenshots/.

Структура папок:
- каждая страница в отдельной папке
- внутри папки скриншоты разных элементов страницы и состояний
- desktop.png - основное состояние на десктопе
- dark.png - тёмная тема 
- mobile.png - мобильная версия

Папки страниц:

- login - страница входа. Десктопная и мобильная версии, темная тема
- dashboard - главная страница. Карточки статистики, таблица последних документов, статусы маршрутов по отделам. Десктоп, тёмная тема, мобильная версия
- documents-list - архив документов. Таблица с фильтрами и пагинацией, фильтры в открытом состоянии. Десктоп, тёмная тема, мобильная версия
- document-card - карточка документа. Все вкладки (обзор, текст OCR, AI-анализ, проверка, история маршрутов, обсуждение). Тёмная тема, мобильная версия
- departments - подразделения. Карточки отделов, активные и архивные. Десктоп, тёмная тема, мобильная версия
- department-detail - страница отдела. Статистика, сотрудники, график, таблица документов. Десктоп, тёмная тема, мобильная версия
- routing - контроль маршрутизации. Таблица с цветовой индикацией, фильтры.  Десктоп, тёмная тема, мобильная версия
- verification - очередь проверки. Таблица документов на проверке.  Десктоп, тёмная тема, мобильная версия
- notifications - уведомления. Группировка по датам и по документам, фильтры.  Десктоп, тёмная тема, мобильная версия
- upload - страница загрузки. Drag-and-drop зона, очередь файлов, шаги обработки, прогресс-бар. Десктоп, тёмная тема, мобильная версия
- analytics - аналитика. Карточки статистики, диаграммы (типы, категории, динамика, статусы). Десктоп, тёмная тема, мобильная версия
- settings - настройки. Все вкладки (провайдер, интерфейс, уведомления, безопасность, справочники, правила маршрутизации, резервное копирование, о системе). Десктоп, тёмная тема, мобильная версия
- profile - профиль пользователя. Аватар, форма редактирования, смена пароля, сессии. Мобильная версия
- sidebar - боковое меню. Развёрнутое и свёрнутое состояние на разных разрешениях
- header - верхняя панель. Выпадающее меню уведомлений, выпадающее меню профиля. Десктоп, тёмная тема, мобильная версия
- search - поиск. Выпадающее меню с результатами быстрого поиска и AI-поиска. Десктоп, тёмная тема, мобильная версия
