# Пояснительная записка

## Введение

Проект «Умный Канцеляр» разработан в рамках производственной практики по направлению «Искусственный интеллект». Задача поставлена в формате проектного кейса: автоматизация входящего документооборота транспортного предприятия.

Транспортные предприятия (метрополитен, железнодорожные компании, автобусные парки) ежедневно получают большое количество входящих документов от контрагентов, государственных органов и граждан. Обработка этих документов в ручном режиме требует значительных временных затрат и подвержена ошибкам, связанным с человеческим фактором.

Разработанная система решает четыре ключевые задачи обработки входящих документов:
- распознавание документов - обработка входящих файлов различных форматов (PDF, изображения, сканы), включая документы низкого качества
- классификация - автоматическое определение типа документа и его тематической категории
- извлечение данных - выделение ключевых сущностей из текста (даты, суммы, контрагенты, ключевые фразы)
- маршрутизация - автоматическое направление документа в соответствующее подразделение на основе его содержания

Цель системы - сокращение времени обработки документов и повышение точности их классификации и распределения.

Система реализована в виде веб-приложения с бэкендом на NestJS, фронтендом на React и базой данных PostgreSQL. Разработка выполнена группой из семи человек.

## Архитектура решения

Система построена по трёхзвенной архитектуре.

- Клиентский слой - одностраничное приложение на React с TypeScript. Использует Vite для сборки, React Router для маршрутизации, Axios для взаимодействия с API. Интерфейс адаптирован для экранов от 320px до широкоформатных мониторов. Поддерживает светлую и тёмную темы оформления.

- Серверный слой - REST API на NestJS с TypeScript. Модульная архитектура: каждый функциональный блок (документы, подразделения, справочники, настройки, уведомления, безопасность, администрирование) выделен в отдельный модуль со своим контроллером, сервисом и DTO. Аутентификация через JWT-токены. Логирование всех запросов в файлы и в базу данных.

- Слой данных - PostgreSQL с расширением pgvector для векторного поиска. База данных содержит 25 таблиц, связанных внешними ключами. TypeORM используется для объектно-реляционного отображения.

- AI-интеграция - анализ документов выполняется через DeepSeek API. Промпт формируется динамически на основе актуальных справочников (типы, категории, отделы - только активные). API-ключ хранится в зашифрованном виде (AES-256-CBC).

## Этапы разработки

Разработка велась в шесть этапов.

1. Этап 1. Базовый сценарий: авторизация пользователя, получение данных дашборда с бэкенда и их отображение на фронтенде. Разработаны JWT-аутентификация, главная страница с карточками статистики, таблица последних документов, статусы маршрутов по отделам.

2. Этап 2. Основной функционал: список документов с фильтрацией и пагинацией, карточка документа с полной информацией (OCR, классификация, источник, история маршрутов), расширенная база данных (добавлены таблицы источников, файлов, OCR-результатов, классификаций).

3. Этап 3. AI-слой: анализ документов через DeepSeek, настройки провайдера, поиск по документам. Добавлены AI-модуль, таблицы ai_settings и document_ai_results, шифрование API-ключа.

4. Этап 4. Загрузка и обработка: загрузка файлов через drag-and-drop, извлечение текста (pdf-parse, mammoth, xlsx, tesseract.js с предобработкой через sharp), автоматический AI-анализ после извлечения текста, удаление документов.

5. Этап 5. Расширенный функционал: уведомления с WebSocket, подразделения с архивацией и графиками, маршрутизация с аналитикой расхождений, настройки системы, тёмная тема, ролевая модель, справочники, правила маршрутизации, резервное копирование, аудит действий.

6. Этап 6. Финализация: админ-панель с полным управлением системой, разграничение ролей администратора и оператора, фильтрация админских уведомлений, очистка журнала действий, полный экспорт и импорт системы, динамические лимиты загрузки, документация, финальное тестирование и исправление недочётов.

## Реализованный функционал

Распознавание документов:
- загрузка файлов через drag-and-drop или выбор, поддержка форматов PDF, DOCX, TXT, XLSX, JPG, PNG, TIFF
- пакетная загрузка до 15 файлов одновременно с прогресс-баром
- сканирование документов с камеры устройства
- автоматическое извлечение текста: PDF через pdf-parse, DOCX через mammoth, XLSX через xlsx, изображения через tesseract.js
- предобработка изображений перед OCR: авто-поворот, изменение размера до 2500x3500, перевод в оттенки серого, нормализация контрастности через sharp
- автоматическая генерация регистрационного номера вида ВХ-2026-XXX
- динамические лимиты загрузки (размер файла, количество, форматы), настраиваемые администратором

Классификация:
- AI-анализ документа через DeepSeek API с динамическим промптом
- автоматическое определение типа документа из справочника (9 типов)
- автоматическое определение категории из справочника (6 категорий)
- расчёт общей уверенности: OCR (20 процентов) плюс AI-анализ (80 процентов)
- поддержка мок-режима для тестирования без API-ключа
- возможность повторного анализа

Извлечение данных:
- выделение ключевых сущностей: дата документа, сумма, контрагент, ключевые фразы
- определение источника документа: тип (организация, физлицо, подразделение), название организации, ФИО отправителя, контактные данные
- цветовые чипы уверенности для каждого извлечённого поля

Маршрутизация:
- рекомендация отдела на основе AI-анализа
- проверка оператором с возможностью корректировки
- применение правил маршрутизации (если тип X и категория Y, то отдел Z)
- сравнение рекомендаций AI с решениями операторов (страница «Контроль маршрутизации»)
- цветовая индикация: зелёный - совпадение, красный - расхождение
- фильтрация по отделу, оператору, типу совпадения
- полная история перемещений документа по отделам

Дополнительный функционал:
- гибкая система фильтрации документов (по типу, категории, статусу, дате)
- пагинация с настраиваемым количеством элементов (5, 10, 20, 50)
- экспорт списка документов в Excel
- два режима поиска: быстрый (точное совпадение) и умный (AI-поиск с пониманием смысла)
- поиск с автодополнением и историей запросов
- уведомления с WebSocket-обновлением в реальном времени (17 типов)
- дашборд с общей статистикой и статусами маршрутов по отделам
- аналитика: диаграммы по типам, категориям, статусам, динамика поступлений
- тёмная тема с полной адаптацией всех компонентов
- адаптивный интерфейс (брейкпоинты 320px, 375px, 480px, 768px, 1024px)
- ролевая модель: администратор и оператор с разными правами
- админ-панель с 6 вкладками: журнал действий, управление пользователями, системные настройки, резервное копирование, статистика, рассылка уведомлений
- очистка журнала действий с настраиваемым сроком
- полный экспорт и импорт всех данных системы
- выборочный экспорт и импорт по разделам

Управление справочниками:
- типы документов: создание, удаление с проверкой связанных документов
- категории: создание, удаление с проверкой связанных документов
- подразделения: создание, архивация (мягкое удаление), восстановление
- детальная страница отдела со статистикой, списком сотрудников и графиком поступлений
- правила маршрутизации: создание и удаление шаблонов

Настройки системы:
- AI-провайдер: выбор модели, ввод API-ключа, проверка подключения
- интерфейс: тема, компактный вид, лимит страниц, отображение уверенности
- уведомления: переключатели типов в двух колонках (документы и система)
- безопасность: сессии, история входов, журнал действий с аватарами и фильтрами
- справочники: управление типами, категориями, отделами
- правила маршрутизации: создание и удаление шаблонов
- о системе: версия, технологии, команда

Безопасность:
- JWT-аутентификация с настраиваемым временем жизни токена
- хэширование паролей через bcrypt
- шифрование API-ключа AI-провайдера (AES-256-CBC)
- отслеживание активных сессий с возможностью принудительного завершения
- история входов с IP-адресами и User-Agent
- полный аудит действий пользователей (более 35 типов действий)
- ролевая модель доступа к эндпоинтам (администратор и оператор)

## Технологический стек

- бэкенд: NestJS, TypeScript, TypeORM, PostgreSQL, JWT, bcrypt, class-validator, Multer, pdf-parse, mammoth, xlsx, tesseract.js, sharp, exceljs
- фронтенд: React, TypeScript, Vite, React Router, Axios, recharts
- база данных: PostgreSQL 15 с расширением pgvector
- стили: CSS с переменными, адаптивная вёрстка, тёмная тема
- AI: DeepSeek API (модели deepseek-chat, deepseek-reasoner)

Точность классификации документов:
- AI-модель определяет тип и категорию с указанием процента уверенности
- оператор проверяет и при необходимости корректирует результат
- создание новых типов и категорий через AI автоматически пополняет справочники

Качество извлечения сущностей:
- извлекаются: дата документа, сумма, контрагент, ключевые фразы
- определяется источник: тип, организация, отправитель, контакты
- все поля отображаются с цветовой индикацией уверенности

Корректность маршрутизации:
- AI предлагает отдел на основе анализа текста
- оператор подтверждает или изменяет решение
- страница контроля маршрутизации показывает статистику совпадений и расхождений

Общая производительность:
- загрузка и обработка файла выполняется в три шага с индикацией прогресса
- пакетная загрузка обрабатывает файлы последовательно
- предобработка изображений ускоряет и улучшает качество OCR

Масштабируемость и устойчивость:
- модульная архитектура NestJS позволяет добавлять новые модули
- PostgreSQL с индексами обеспечивает быструю работу с данными
- Docker-контейнеризация упрощает развёртывание

Удобство интеграции:
- REST API с документированными эндпоинтами
- экспорт данных в JSON и Excel
- импорт данных из JSON

Интерфейс пользователя:
- адаптивный дизайн для всех типов устройств
- единый стиль оформления
- тёмная тема

- админ-панель с удобным управлением системой
