# Отчёт о тестировании

## Методика тестирования

Тестирование проводилось на всех этапах разработки участниками команды. Каждый участник тестировал страницы, закреплённые за другими разработчиками, для обеспечения независимой проверки.

Виды тестирования:
- функциональное тестирование - проверка работы всех элементов интерфейса и API
- тестирование адаптива - проверка отображения на пяти брейкпоинтах
- тестирование тёмной темы - проверка всех страниц и компонентов
- тестирование безопасности - проверка доступа к защищённым эндпоинтам
- тестирование обработки ошибок - проверка реакции на некорректные данные
