# План презентации

## Структура слайдов

Количество слайдов: 12-15.

### Слайд 1. Титульный

Умный Канцеляр = автоматизация входящего документооборота транспортной компании

### Слайд 2. Проблема

Транспортные предприятия ежедневно получают десятки входящих документов от контрагентов, государственных органов и граждан. Обработка вручную - это долго, дорого и с ошибками.

Что нужно автоматизировать:
- распознавание текста из сканов и файлов
- классификация по типам и категориям
- извлечение ключевых данных (даты, суммы, контрагенты)
- маршрутизация в нужное подразделение

### Слайд 3. Решение

Система «Умный Канцеляр» - веб-приложение с AI-анализом документов.

Четыре шага обработки:
- загрузка документа (drag-and-drop, сканирование с камеры)
- извлечение текста (pdf-parse, mammoth, tesseract.js)
- AI-анализ (DeepSeek: тип, категория, отдел, сущности)
- проверка оператором и маршрутизация

### Слайд 4. Технологический стек

- бэкенд: NestJS, TypeScript, TypeORM, PostgreSQL
- фронтенд: React, TypeScript, Vite, recharts
- AI: DeepSeek API (deepseek-chat, deepseek-reasoner)
- инфраструктура: Docker, JWT, bcrypt, AES-256-CBC
