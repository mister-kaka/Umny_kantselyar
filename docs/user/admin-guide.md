# Руководство администратора

## Вход в систему

Используйте учётную запись с ролью администратора:
- alexandra@umny-kan.ru / admin123
- maria.n@umny-kan.ru / admin123

После входа доступен полный функционал системы, включая административные разделы.

## Отличия от оператора

Администратор имеет доступ ко всем функциям оператора плюс:
- настройка AI-провайдера
- полное управление справочниками (удаление типов, категорий, отделов)
- архивация и восстановление отделов
- удаление правил маршрутизации
- резервное копирование и восстановление данных
- доступ к разделу «Администрирование»

## Администрирование

Раздел: Администрирование в боковом меню.

Раздел доступен только администратору и содержит шесть вкладок для управления системой.

### Журнал

Отображает все действия пользователей в системе.

Возможности:
- поиск по ФИО или email пользователя
- фильтр по типу действия
- фильтр по дате
- настройка количества записей на странице
- сброс всех фильтров
- удаление записей старше указанного количества месяцев

Колонки таблицы: дата, пользователь, действие, документ, описание.

### Пользователи

Управление учётными записями пользователей.

Возможности:
- просмотр списка всех пользователей
- поиск по ФИО или email
- фильтр по роли (все, администраторы, операторы)
- создание нового пользователя: ФИО, email, пароль, роль, отдел
- смена роли пользователя
- блокировка и разблокировка пользователя
- сброс пароля пользователя
- удаление пользователя с просмотром статистики (документов, комментариев, сессий)

Нажмите на пользователя для открытия карточки с подробной информацией и действиями.

### Система

Управление системными настройками.

Ограничения загрузки:
- максимальный размер файла (МБ)
- максимальное количество файлов за одну загрузку
- разрешённые форматы файлов (PDF, DOCX, TXT, XLSX, JPG, JPEG, PNG, TIFF)
- кнопка «Сохранить» для применения настроек

Очистка данных:
- удаление документов старше указанного количества месяцев
- удаление прочитанных уведомлений старше указанного количества месяцев
- кнопка «Выполнить очистку» для каждого типа
- предупреждение о необратимости действий

Логи сервера:
- скачивание логов за текущую дату
- скачивание логов за выбранный период (с даты по дату)

### Резервное копирование

Управление резервными копиями данных.

Полная копия:
- экспорт полной копии всех данных системы в файл JSON
- импорт полной копии из файла JSON (все текущие данные будут заменены)

Выборочный экспорт:
- выбор разделов для экспорта: документы, справочники, пользователи, настройки, история маршрутов, аудит
- кнопка «Экспортировать выбранное»
- кнопка «Экспортировать всё»

Выборочный импорт:
- выбор файла для импорта
- выбор разделов для импорта: документы, справочники, пользователи
- предупреждение о замене выбранных данных
- кнопка «Импортировать»

### Статистика

Общая статистика системы.

Карточки метрик:
- всего документов
- пользователей
- средняя уверенность AI
- маршрутов

Документы по статусам:
- столбчатая диаграмма распределения документов по статусам
- цветовая индикация статусов

Активность пользователей:
- таблица с количеством действий каждого пользователя
- полоска прогресса для визуального сравнения активности

### Уведомления

Рассылка уведомлений пользователям.

Форма рассылки:
- выбор получателей: все, администраторы, операторы, выбрать конкретных
- при выборе «Выбрать» - список пользователей для отметки
- поле заголовка уведомления
- поле текста сообщения
- кнопка «Отправить»

История рассылок:
- таблица с датой, заголовком и количеством получателей
- фильтр по дате
- пагинация

## Настройка AI-провайдера

Раздел: Настройки - Провайдер.

Для работы AI-анализа документов необходимо настроить подключение к AI-провайдеру.

1. Выберите провайдера из выпадающего списка
2. Выберите модель
3. Введите API-ключ, полученный от провайдера
4. При необходимости измените Base URL (для прокси или зеркал)
5. Нажмите «Проверить подключение» для тестирования
6. При успешной проверке нажмите «Сохранить»

API-ключ хранится в зашифрованном виде. При повторном открытии настроек ключ не отображается - поле будет пустым. Если нужно изменить ключ, введите новый.

## Управление справочниками

Раздел: Настройки - Справочники.

### Типы документов

Типы документов используются для классификации. AI предлагает тип при анализе, оператор может изменить.

- создание: введите название в поле «Новый тип» и нажмите «Добавить» или Enter
- удаление: нажмите крестик на чипсе с названием типа
- система проверит, есть ли документы этого типа. Если есть - удаление будет запрещено

### Категории

Категории используются для тематической группировки документов.

- создание: введите название в поле «Новая категория» и нажмите «Добавить» или Enter
- удаление: нажмите крестик на чипсе с названием категории
- система проверит, есть ли документы этой категории. Если есть - удаление будет запрещено

### Отделы

Отделы используются для маршрутизации документов.

- создание: введите название в поле «Новый отдел» и нажмите «Добавить» или Enter. Код отдела генерируется автоматически (транслитерация названия)
- архивация: нажмите кнопку «Архивировать» напротив отдела. Отдел будет скрыт из общих списков, но история маршрутов сохранится. AI перестанет предлагать этот отдел
- восстановление: для архивных отделов доступна кнопка «Восстановить». Отдел вернётся в активные списки

При попытке создания дубликата (отдел с таким кодом уже существует) система покажет ошибку.

## Управление отделами через раздел «Подразделения»

Раздел «Подразделения» в боковом меню также позволяет управлять отделами.

- создание: кнопка «Добавить отдел» в верхней части страницы
- архивация: иконка корзины на карточке отдела. Появляется модальное окно с информацией о количестве документов в истории и последнем документе
- восстановление: переключитесь на вкладку «Архивные» и нажмите «Восстановить» на карточке нужного отдела

На странице отдела (клик по карточке) также доступны кнопки «Архивировать» и «Восстановить».

## Правила маршрутизации

Раздел: Настройки - Правила маршрутизации.

Правила маршрутизации позволяют автоматически предлагать отдел для документа на основе его типа и категории. При проверке документа оператор может выбрать правило - и отдел заполнится автоматически.

Создание правила:
1. Нажмите «+ Создать правило»
2. В модальном окне выберите тип документа из выпадающего списка
3. Выберите категорию из выпадающего списка
4. Выберите отдел, в который будет направляться документ
5. Нажмите «Создать»

Удаление правила:
- нажмите кнопку «Удалить» в строке с правилом

Созданные правила отображаются в карточке документа на вкладке «Проверка» в выпадающем списке «Применить правило».
