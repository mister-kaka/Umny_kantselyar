# Руководство оператора

## Вход в систему

1. Откройте страницу входа в браузере
2. Введите email и пароль, выданные администратором
3. При необходимости отметьте «Запомнить меня» для сохранения входа
4. Нажмите кнопку «Войти»

После входа откроется главная страница (дашборд).

## Главная страница

На главной странице отображается:
- приветствие и текущая дата
- три карточки статистики: всего входящих документов, направлено в отдел, ожидают проверки
- таблица последних документов с возможностью перехода в карточку
- статусы маршрутов по отделам

Навигация по разделам системы выполняется через боковое меню слева.

## Загрузка документов

Для загрузки нового документа:
1. Перейдите в раздел «Входящие документы» через боковое меню или кнопку загрузки в верхней панели
2. Перетащите файлы в область загрузки или нажмите на неё для выбора файлов
3. Можно загрузить до 15 файлов одновременно
4. Поддерживаются форматы: PDF, DOCX, TXT, XLSX, JPG, PNG, TIFF
5. Максимальный размер одного файла - 50 МБ
6. Выберите нужные файлы галочками и нажмите «Загрузить»
7. Система автоматически выполнит три шага: загрузку файла, извлечение текста и AI-анализ
8. После завершения нажмите «Приступить к проверке» для перехода к проверке документов

Администратор может изменить доступные форматы, максимальный размер файла и количество файлов. Актуальные ограничения отображаются на странице загрузки в правой панели.

Также доступно сканирование документов с камеры - кнопка «Сканировать» в верхней части страницы загрузки и в верхней панели.

## Проверка документов

### Очередь проверки

В разделе «Очередь проверки» отображаются все документы, ожидающие проверки оператором. Для каждого документа показаны:
- регистрационный номер
- название файла
- дата загрузки
- тип документа, предложенный AI
- уверенность AI в процентах (если включена в настройках)
- статус

Чтобы начать проверку, нажмите кнопку «Взять в проверку» в строке документа.

## Маршрутизация

В разделе «Маршрутизация» отображается сравнение рекомендаций AI с решениями операторов.

Документы с зелёной полоской слева - AI и оператор выбрали один отдел (совпадение).
Документы с красной полоской слева - AI и оператор выбрали разные отделы (расхождение).

Возможности:
- фильтрация по типу совпадения (все, совпадения, расхождения)
- фильтрация по отделу и оператору
- пагинация с выбором количества
- переход в карточку документа
- переход в карточку отдела

## Архив документов

В разделе «Архив» отображаются все документы в системе.

Возможности:
- фильтрация по типу документа, категории, статусу, дате загрузки
- пагинация с выбором количества документов на странице
- экспорт отфильтрованного списка в Excel
- массовое удаление выбранных документов
- переход в карточку документа кликом по строке

## Карточка документа

Карточка документа открывается при клике на документ из любого списка (архив, проверка, маршрутизация, уведомления, подразделение).

В верхней части карточки находятся:
- кнопка возврата на страницу, с которой был выполнен переход. Текст кнопки зависит от источника перехода: «На главную», «В очередь проверки», «К маршрутизации», «К уведомлениям», «Назад в отдел», «Архив документов»
- регистрационный номер документа
- общая уверенность в процентах - рассчитывается как OCR (качество распознавания) на 20 процентов плюс AI-анализ на 80 процентов. Отображается в виде цветного бейджа: зелёный (высокая), жёлтый (средняя), красный (низкая). Может быть скрыта через настройки интерфейса
- кнопка «Редактировать» - открывает модальное окно редактирования основных полей документа (название, тип, категория, дата, отправитель, источник, сумма)
- кнопка удаления документа (иконка корзины) - удаляет документ и все связанные файлы без возможности восстановления
- кнопка "Перейти в архив документов" (иконка архива) - для перехода к общему списку

Карточка документа содержит несколько вкладок.

Вкладка «Обзор»:
- общая информация о документе
- классификация (тип, категория) с процентами уверенности AI
- источник документа (организация, отправитель, контакты)
- прикреплённые файлы с возможностью предпросмотра и скачивания

Вкладка «Текст OCR»:
- распознанный текст документа
- точность распознавания
- кнопки копирования и повторного распознавания

Вкладка «AI-анализ»:
- результаты анализа: предложенные тип, категория, отдел
- уверенность модели
- извлечённые данные: дата, сумма, контрагент, ключевые фразы
- краткая сводка
- кнопка повторного анализа

Вкладка «Проверка» - основной инструмент оператора:
1. Проверьте тип документа. При необходимости выберите другой из списка или введите новый
2. Проверьте категорию. При необходимости выберите другую или введите новую
3. Выберите отдел для направления. Можно выбрать из списка или применить правило маршрутизации (если настроено администратором)
4. При необходимости укажите дату документа и отправителя
5. Добавьте комментарий к проверке (необязательно)
6. Нажмите «Подтвердить» для сохранения проверки
7. Нажмите «Направить в отдел» для отправки документа

Кнопка «Отклонить» позволяет отклонить документ с указанием причины.

Вкладка «История маршрутов»:
- список всех перемещений документа по отделам
- статус каждого маршрута
- причина направления
- дата направления
- кнопка перехода в карточку отдела

Вкладка «Обсуждение»:
- комментарии к документу
- возможность добавить новый комментарий
- возможность удалить свой комментарий

## Подразделения

В разделе «Подразделения» отображаются карточки всех активных отделов.

Для каждого отдела показано:
- название
- количество направленных документов
- шкала загруженности (зелёный - низкая, жёлтый - средняя, красный - высокая)
- последний направленный документ

Возможности:
- сортировка по названию или загруженности
- просмотр детальной информации об отделе (клик по карточке)
- переключение между активными и архивными отделами

Оператор может только просматривать подразделения. Создание, архивация и восстановление отделов доступны только администратору.

## Страница отдела

Открывается при клике на карточку отдела в разделе «Подразделения» или по ссылке из карточки документа.

В верхней части страницы:
- кнопка возврата к списку подразделений
- название отдела с иконкой
- три карточки статистики: всего направлено документов, дата первого поступления, дата последнего поступления

Сотрудники отдела:
- список сотрудников, закреплённых за отделом
- аватар, имя и email каждого сотрудника

График динамики поступлений:
- показывает количество документов, направленных в отдел по месяцам
- возможность выбора периода: 1 месяц, 3 месяца, 6 месяцев, 12 месяцев, всё время
- возможность указать свой диапазон дат
- при наведении на точку графика показывается точное количество документов за месяц

Документы, направленные в отдел:
- таблица со списком всех документов, направленных в этот отдел
- колонки: регистрационный номер, название, тип документа, оператор, причина, дата направления
- клик по строке открывает карточку документа

## Аналитика

В разделе «Аналитика» отображается статистика по документам:
- общие показатели (всего документов, средняя уверенность, отклонено, за 7 дней, требуют проверки, обработано AI)
- круговая диаграмма по типам документов
- столбчатая диаграмма по категориям
- линейный график динамики поступлений за 14 дней
- столбчатая диаграмма по статусам обработки

## Настройки

Доступны в боковом меню. Содержат шесть вкладок для оператора.

Вкладка «Интерфейс»:
- включение компактного вида (уменьшенные отступы и шрифты)
- отображение или скрытие показателей уверенности AI
- лимит документов на странице по умолчанию (5, 10, 20, 50)
- выбор темы (светлая или тёмная)
- сохранение настроек

Вкладка «Уведомления» - настройка типов уведомлений в двух колонках:
- Документы: новый документ, документ готов, ошибка извлечения текста, ожидание проверки, направлен в отдел, отклонён, проверен, низкая уверенность, документ удалён
- Система: смена пароля, обновление профиля, изменение настроек, новый вход, новый комментарий, создание справочника, удаление справочника
- Сообщения администратора всегда включены и не могут быть отключены
- каждый тип включается или выключается переключателем
- сохранение настроек

Вкладка «Безопасность»:
- активные сессии с возможностью завершения
- история входов с фильтром по дате и пагинацией
- журнал действий с аватарами пользователей, переводом действий на русский язык и описанием
- удаление записей в журнале старше указанного количества месяцев
- кнопка выхода со всех устройств

Вкладка «Справочники»:
- типы документов: просмотр, создание
- категории: просмотр, создание
- отделы: просмотр
- удаление типов, категорий и управление отделами доступны только администратору

Вкладка «Правила маршрутизации»:
- описание работы правил
- список созданных правил
- создание нового правила через кнопку «+ Создать правило»
- удаление правил доступно только администратору

Вкладка «Провайдер»:
- просмотр текущих настроек AI-провайдера и модели
- изменение настроек доступно только администратору

Вкладка «О системе»:
- название и версия системы
- список технологий
- информация о команде разработчиков

## Уведомления

В разделе «Уведомления» отображаются все системные уведомления.

В верхней панели сайта (колокольчик) показывается счётчик непрочитанных уведомлений.

Типы уведомлений:
- загружен новый документ
- документ обработан (текст распознан, AI-анализ выполнен)
- ошибка распознавания
- требуется проверка
- документ направлен в отдел
- документ отклонён
- документ проверен
- низкая уверенность AI
- сообщение администратора (системные настройки, рассылки)

Возможности:
- группировка по датам или по документам
- фильтрация по типу и дате
- отметка прочитанными (по одному или все сразу)
- массовое удаление уведомлений
- удаление только прочитанных уведомлений
- переход к документу из уведомления
- настройка типов уведомлений в разделе «Настройки»

## Профиль

В разделе «Профиль» в верхней панели сайта можно:
- просмотреть информацию о себе
- изменить имя и email
- загрузить или изменить аватар
- сменить пароль
- просмотреть активные сессии
- завершить сессии на других устройствах

## Поиск документов

Поиск находится в верхней панели сайта. Поддерживает два режима: быстрый поиск и умный поиск (AI). Переключение между режимами выполняется кнопкой справа от поля ввода.

### Быстрый поиск

Рекомендуется начинать поиск с этого режима.

Особенности:
- ищет точные совпадения по всему содержимому документов
- не понимает смысл запроса, ищет по словам
- работает мгновенно

Примеры запросов:
- ВХ-2026-005 - найдёт документ по регистрационному номеру
- договор поставки - все документы, содержащие эти слова
- бухгалтерия - документы, уже назначенные в этот отдел
- Лукойл - все документы от этого отправителя

Если быстрый поиск не дал результата, система предложит переключиться на умный поиск.

### Умный поиск (AI)

Используется когда быстрый поиск не дал результата или требуется найти документы по смыслу, а не по точным словам.

Особенности:
- понимает суть запроса
- исправляет опечатки и неверную раскладку клавиатуры
- определяет тип, категорию и отдел из формулировки запроса
- в большинстве случаев находит точнее быстрого

Примеры запросов:
- счета от Лукойла - поймёт тип документа и отправителя
- бухгалтерия - все документы для этого отдела, даже если ещё не назначены оператором
- ДТП март - найдёт акты о происшествиях за март
- ГИБДД - поймёт аббревиатуру государственного органа

Работает медленнее быстрого. AI не гарантирует абсолютную точность.

### Подсказки и история

При вводе текста в поле поиска:
- появляются подсказки на основе частых запросов: договор, счёт, акт, письмо, обращение и другие
- отображается история последних пяти поисковых запросов при пустом поле

Клик по подсказке или элементу истории сразу выполняет поиск.

### Результаты поиска

Результаты появляются в выпадающем меню под полем поиска с задержкой 400 мс в быстром режиме и 600 мс в умном. Для каждого найденного документа показывается регистрационный номер, название, отправитель и статус. Клик по результату открывает карточку документа. Нажатие Enter при одном результате сразу открывает документ.

В нижней части выпадающего меню отображается общее количество найденных документов и режим поиска.
