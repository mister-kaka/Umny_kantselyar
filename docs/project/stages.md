# Этапы разработки

## Этап 1 - Базовый сценарий

Результат:
- локально поднятый NestJS-бэкенд и PostgreSQL в Docker
- два рабочих эндпоинта: POST /auth/login и GET /dashboard/data
- JWT-аутентификация, bcrypt, валидация DTO, CORS, логирование
- React-приложение с TypeScript и Vite
- страница входа с валидацией и запоминанием
- дашборд с карточками статистики и таблицей последних документов
- общие компоненты: Card, Table, Header, Sidebar
- глобальные CSS-переменные и единый дизайн
- API-сервис с настройками Axios

## Этап 2 - Основной функционал

Результат:
- модуль Documents: список с фильтрацией и пагинацией, карточка с полной информацией
- справочные эндпоинты: типы, категории, отделы
- 4 новые таблицы: document_sources, document_files, ocr_results, document_classifications
- страница списка документов с таблицей, фильтрами и пагинацией
- страница карточки документа с вкладками (обзор, текст OCR, сущности, история маршрутов)
- обновлённый дашборд с едиными цветами статусов и регистрационными номерами
- адаптив страниц списка и карточки

## Этап 3 - AI и настройки

Результат:
- AI-модуль: анализ документов через DeepSeek API
- шифрование API-ключа (AES-256-CBC), мок-режим
- таблицы ai_settings и document_ai_results
- модуль Settings: настройки AI, список провайдеров
- поиск по документам
- страница настроек AI
- вкладка AI-анализ в карточке документа с цветными чипами уверенности
- поиск в Header с debounce и выпадающим меню
- исследование форматов файлов, архив тестовых файлов
- адаптив настроек, поиска и AI-блока

## Этап 4 - Загрузка файлов и OCR

Результат:
- загрузка файлов через drag-and-drop (POST /documents/upload)
- извлечение текста (pdf-parse, mammoth, xlsx, tesseract.js)
- валидация форматов, авто-генерация регистрационного номера
- удаление документов
- страница загрузки с цепочкой статусов
- сканирование с камеры
- обновлённая карточка документа
- адаптив страницы загрузки

## Этап 5 - Расширенный функционал

Результат:
- улучшение OCR через sharp (авто-поворот, бинаризация, нормализация)
- автозаполнение полей документа после AI-анализа
- эндпоинты верификации, маршрутизации, редактирования документов
- модуль профиля (GET/PUT /auth/profile, аватар, смена пароля)
- настройки уведомлений и интерфейса
- модуль безопасности (сессии, история входов, аудит-лог)
- поиск по OCR-тексту, экспорт в Excel
- шаблоны маршрутизации, комментарии к документам
- журнал действий (audit_log)
- сроки обработки документов
- страница уведомлений с WebSocket и группировкой
- страница очереди проверки
- страницы подразделений и маршрутизации (переработанные)
- страница аналитики с графиками
- расширенные настройки (8 вкладок)
- тёмная тема
- ролевая модель
- страница профиля
- доработки карточки документа
- иконки, валидация справочников, уведомления для справочников

## Этап 6 - Финализация

Результат:
- полная техническая документация
- пользовательская документация
- отчётная документация
- ролевая модель (администратор и оператор) с разграничением доступа
- админ-панель с 6 вкладками: журнал, пользователи, система, резервное копирование, статистика, уведомления
- управление пользователями: создание, блокировка, сброс пароля, смена роли, удаление
- системные настройки: ограничения загрузки, очистка данных, логи сервера
- полное и выборочное резервное копирование (экспорт/импорт)
- массовая рассылка уведомлений администратором
- статистика системы: документы по статусам, активность пользователей
- скрытие административных функций у оператора
- отображение актуальных настроек загрузки на странице загрузки
- улучшенная вкладка безопасности в настройках с фильтрами и пагинацией
- очистка журнала действий
- модальное окно создания правил маршрутизации
- перевод всех типов уведомлений и действий в журнале
- обязательные уведомления администратора (не отключаются)
- финальная проверка адаптива всех страниц
- тестирование всех сценариев
- исправление визуальных недочётов
- подготовка презентации
