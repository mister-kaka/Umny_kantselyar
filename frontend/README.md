# Фронтенд Умного Канцеляра

## Быстрый старт

Требования: Node.js 18+, npm 9+

1. Установка зависимостей:
  - npm install

2. Запуск:
  - npm run dev

Приложение будет доступно на http://localhost:3001.

ВАЖНО: для полноценной работы необходимо запустить бэкенд (инструкция в backend/README.md).

## Полезные команды

- Ctrl+C - остановка процесса
- npm run build - продакшн-сборка
