# Frontend для Умного Канцеляра

## Быстрый старт проекта: 

ВАЖНО: для ПОЛНОЦЕННОГО запуска проекта, необходимо поднять и бэкенд и фронтенд.

### 1. Установка зависимостей 
- cd frontend
- npm install

### 2. Запуск фронтенда
npm run dev

Приложение будет доступно по адресу:   
http://localhost:3000

## Требования: 
- Node.js 18 и выше;
- npm 9 и выше

## Проверка работоспособности
- http://localhost:3000  (при npm start открывается автоматически):
    Пустая страница.
- http://localhost:3000/login
    Должна открыться страница логина
- http://localhost:3000/dashboard
    Должна открыться страница дашборда (Главная)

Важно: пока переход с авторизацией со страницы логина на страницу дашборда не осуществлен.

## Полезные команды
- npm run dev   // запуск в режиме разработки
- Ctrl + C     // остановка процесса npm start

## Текущий статус части фронтенда

### Инфраструктура:
- Создан базовый каркас React-приложения, настроен TypeScript
- Настроен роутинг (страницы логина и дашборда)
- Добавлены общие компоненты (Card, Table, Header, Sidebar)
- Добавлены UI-правила: CSS-переменные и дизайн в Figma
- Vite подключён 

### 2. Логин
- Вёрстка страницы логина
- Состояния (email, password, rememberMe, ошибки)
- Валидация формы (email, пароль не менее 6 символов)
- Адаптив страницы логина (мобильные, планшеты, десктоп)
- Подключение к API (login)
- Сохранение токена (localStorage / sessionStorage)
- Редирект на дашборд после успешного входа
- Обработка ошибок (неверный email/пароль)

### 3. Дашборд
- Вёрстка страницы дашборда
- Sidebar (сворачивание/разворачивание)
- Header (поиск, иконки, профиль)
- Главное меню (MainMenu) с карточками и таблицей
- Подключение к API (getDashboardData)
- Отображение реальных данных:
  - Карточки (всего документов, в обработке, требуют проверки)
  - Таблица последних документов
  - Статусы маршрутов по отделам (с группировкой)
- Перевод статусов на русский
- Состояния loading и error
- Кнопка "Повторить" при ошибке

### 4. Защита маршрутов
- Компонент ProtectedRoute (проверка токена)
- Перекидывание на /login при отсутствии токена
- Защита страницы дашборда от неавторизованного доступа

### 5. Адаптив
- Адаптив страницы логина 
- Адаптив страницы дашборба (в процессе, часть Марии Мотовиловой)

### 6. Интеграция
- API-функции (login, getDashboardData)
- Axios с перехватчиками (токен, 401)
- Типы (LoginResponse, RecentDocument, DepartmentRouteStatus, DashboardData, GroupedDepartment, DepartmentStatus)
- Полный сценарий: логин - дашборд - данные
